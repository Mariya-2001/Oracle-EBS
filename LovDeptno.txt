-- Create LOV for DEPTNO --


1. ORACLE FORMS 
2. OPEN EXISTING .FMB (MARIYA_EMP_LOV.FMB)
3. CLICK LOV --> CLICK GREEN + SIGN
4. WIZARD
5. NEW RECORD --> NEXT
6. WRITE A QUERY: SELECT DEPTO FROM EMP --> next
7. MOVE DEPTNO TO LOC COLUMN --> next 
8. CLICK IN RETURN VALUE FIELD --> CLICK LOOK UP RETURN ITEM --> CLICK OK 
9. FILED WILL BE (EMP.EMPNO)
10. GIVE TITLE :LOV FOR DEPTNO --> NEXT --> NEXT 
11. MOVE TO ITEMS --> NEXT --> FINISH
12. LOV AND RECORD GROUP CREATED 
13. SAVE AND COMPILE

-- Register the form in EBS --

1. MOVE THE COMPILED FORM TO ORACLE EBS SERVER USING WINSCP (\u01\.....\fnd\12.0.0\forms\US)
2. LOGIN TO EBS
3. GO TO APPLICATION DEVELOPER --> APPLICATION 
	- FORM 		(CREATE)
	- FUNCTION 	(CREATE)
	- MENU 		(QUERY AND ATTACH THE FORM)
4. SWITCH TO MARIYS_RESP RESPONSIBILITY
	- OPEN MENU (PERFORM INSERT , UPDATE AND DELETE)
