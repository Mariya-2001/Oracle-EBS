-- Create a report as .rtf based on Parameter report --

1. USE AN EXISTING PARAMETER REPORT (MARIYAPARREPORT)
2. OPEN MY RESPONSIBILITY --> VIEW --> REQUEST --< SUBMIT A NEW REQUEST --> CHOOSE THE MARIYAPARREPORT
3. VIEW THE OUTPUT
4. SAVE THE OUTPUT BY RIGHT CLICK IN THE PAGE --> SAVE PAGE AS --> WRITE THE NAME --> WEB PAGE, COMPLETE --> SAVE
5. OPEN MS WORD 
6. GO TO THE TAB BI PUBLISHER --> SAMPLE XML --> UPLOAD THE SAVED XML FILE FROM STEP 11
7. TABLE WIZARD -->  TABLE --> NEXT  --> MOVE ALL COLUMNS TO THE RIGHT  --> GROUP BY DEPTNO --> SORT BY DNAME --> FINISH
8. A REPORT WILL BE GENERATED IN THE WORD FILE
9. SAVE THE WORD DOCUMENT AS .RTF
10. OPEN AS PDF OR HTML TO SEE THE FULL OUTPUT
