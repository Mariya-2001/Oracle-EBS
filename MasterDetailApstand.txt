-- Create a Master-Detail Form using DEPT and EMP tables --

-- Design the Form on APSTAND.fmb tamplate --

-- Register the Form in Oracle EBS --


1. OPEN ORACLE FORM BUILDER
2. OPEN APSTAND.FMX
3. SAVE AS MARIYA_MASTER_DETAIL_APSTAND.FMB
4. IN DATA BLOSK --> DELETE BLOCKNAME
5. IN CANVAS --> DELETE BLOCKNAME 
6. IN WINDOW --> DELETE BLOCKNAME
7. CREATE NEW WINDOW AND NAME IT AS: MASTER_DETAIL_EMP_DEPT
8. CREATE NEW CANVAS AND NAME IT AS: MASTER_DETAIL_DEPT_EMP_CAN
9. CREATE A CANVAS AND NAME IT AS: DEPT_EMP_CANVAS
10. CREATE DATA BLOCK:
	- CLICK DATA BLOCK --> PRESS (+) BUTTON
	- CHOOSE USE THE DATA BLOCK WIZARD --> OK --> NEXT
	- CHOOSE TABLE OR VIEW --> NEXT
	- BROWSE TABLE TABLE
	- MOVE ALL AVAILABLE COLUMNS TO DATABASE ITEMS (FROM LEFT TO RIGHT) --> CLICK NEXT
	- OK --> FINISH (CHOOSE A FORM)
11. CREATE ANOTHER DATA BLOCK FOR DEPT TABLE AND MAKE A RELATIONSHIP TO THE EMP TABLE. (CHOOSE A TABULAR)
12. SAVE AS MARIYA_MASTER_DETAIL_APSTAND.FMB
13. COMPILE MARIYA_MASTER_DETAIL_APSTAND.FMX

14. OPEN EBS
15. APPLICATION DEVELOPER  --> APPLICATION --> FORM --> CREATE (MARIYA_MASTER_DETAIL_APSTAND)
					       FUNCTION --> CREATE (MARIYA_MASTER_DETAIL_APSTAND)
					       MENU --> QUERY and ATTACH THE FORM 

15. SWITCH TO YOUR RESPONSIBILITY --> FORMS RESPONSIBILITY 
--> Open MARIYA_MASTER_DETAIL_APSTAND
