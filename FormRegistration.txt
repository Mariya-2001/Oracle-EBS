-- Register Form in EBS -- 
 

1. OPEN EBS
2. SWITH TO APPLICATION DEVELOPER -->   APPLICATION --> FORM
					APPLICATION --> FUNCTION
					APPLICATION --> MENU (MARIYA_FORM_MENU) 


3. CREATE NEW RESPONSIBILITY 
   -SYSTEM ADMINISTRATOR --> SECURITY --> RESPONSIBILITY --> DEFINE 
   -RESP NAME : MARIYA_FORMS_RESP 
   -APPLICATION :Application Object Library
   -RESP KEY : MARIYA_FORMS_RESP
   -DATA GROUP --> NAME        : STANDARD
		   APPLICATION :Application Object Library
   -MENU: MARIYA_FORM_MENU

4. SWITCH TO THE NEW RESPONSIBILITY ( MARIYA_FORMS_RESP ) 
	MENU --> MARIYA_FORM_MENU
	FUNCTION --> MariyaEmp
