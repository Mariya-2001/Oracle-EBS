-- Create report and register it in EBS with parameters -- 

Make a Report:
1. Open Report Builder 
2. Double Click on report 
3. Select Wizard --> OK --> next 
4. Click Create Both Web and Paper Layout --> next 
5. Give a title:  , Choose tablular
6. Sql query  --> next
7. Write: SELECT * FROM EMP; --> NETX --> OK 
8. CLICK ALL FIELDS --> MOVE TO THE RIGHT 
8. SELECT COUNT(DEPTNO) , SUM(SAL) --> NEXT --> FINISH
9. Save the Report as .rdf
10. Move the .rdf to EBS using WINScp
