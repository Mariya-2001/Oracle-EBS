-- CREATE MASTER DETAIL REPORT --

1. OPEN REPORTS BUILDER
2. CHOOSE WIZARD --> OK --> NEXT
3. CREATE BOTH WEB AND PAPER --> NEXT --> CHOOSE GROUP ABOVE
4. SQL QUERY --> NEXT --> QUERY BUILDER --> CHOOSE DEPT AND EMP --> TICK ALL COLUMNS --> OK
5. MOVE DEPTNO TO THE GROUP LIST --> NEXT --> MOVE ALL EXCEPT THE LAST ONE TO THE DISPLAYED FIELDS --> NEXT
6. CHOOSE SAL COUNT , DEPTNO COUNT --> NEXT --> FINISH
7. SAVE THE REPORT AS MARIYA_MASTER_DETAIL.RDF
8. MOVE THE MARIYA_MASTER_DETAIL.RDF TO EBS USING WINScp TO THIS LOCATION ..../12.0.0/REPORTS/US
9. CREATE EXECUTABLE --> CREATE PROGRAM --> ADD MARIYA_MASTER_DETAIL.RDF TO REQUEST GROUP
10. SWITCH TO MARIYA_RESP --> VIEW --> REQUEST --> SUBMIT A REQUEST 


11. SAVE THE OUTPUT BY RIGHT CLICK IN THE PAGE --> SAVE PAGE AS --> WRITE THE NAME --> WEB PAGE, COMPLETE --> SAVE
12. OPEN MS WORD 
13. GO TO THE TAB BI PUBLISHER --> SAMPLE XML --> UPLOAD THE SAVED XML FILE FROM STEP 11
14. TABLE WIZARD -->  TABLE --> NEXT  --> MOVE ALL COLUMNS TO THE RIGHT  --> GROUP BY DEPTNO --> SORT BY DNAME --> FINISH
15. A REPORT WILL BE GENERATED IN THE WORD FILE
16. SAVE THE WORD DOCUMENT AS .RTF
16. OPEN AS PDF OR HTML TO SEE THE FULL OUTPUT
