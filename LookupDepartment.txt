-- Create LOOKUP for DEPARTMENT -- 

1. APPLICATION DEVELOPER --> APPLICATION --> LOOKUPS --> COMMON
2. 	NAME:MARIYA_LOOKUP_DEPT
	MEANING:MARIYA_LOOKUP_DEPT
	APPLICATION: APPL
	DESC: TEST FOR CREATING A LOOKUP FOR DEPARTMENT	
ACCESS LEVEL: EXTENSIBLE

CODE		MEANING			DESCRIPTION
FIN		FINANCE			FINANCE
IT		INFORMATION TECHNOLOGY	INFORMATION TECHNOLOGY
SALES		SALES			SALES DEPDT

3. SAVE
4. EXIT --> OPEN AGAIN THE LOOKUPS
5. QUERY BE EXAMPLE --> ENTER --> MARIYA% --> QUERY BY EXAMPLE --> RUN
6. ADD TWO ADDITIONl RECORDS
	CODE	MEANING		DESCRIPTION	
	MKTG	MARKETING	MARKETING DEPARTMENT
	PROD	PRODUCTION	PRODUCTION


TO QUERY THE LOOKUP:
1. OPEN SQL PLUS
2. WRITE: 
SQL> SELECT LOOKUP_TYPE FROM FND_LOOKUP_TYPES
  2  WHERE LOOKUP_TYPE LIKE 'MARIYA%';
